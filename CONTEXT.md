# Riley's Pub Website

## Project Overview

Building a modern marketing website for Riley's Pub, a neighborhood Irish pub in St. Louis, Missouri.

The goal is to create a professional, responsive website that captures the atmosphere of the pub while serving as a real-world portfolio project and potentially becoming a production-ready business site.

Current focus is on architecture, design system development, and reusable UI components.

# Current Problem

Refactor was completed, but visual styling is not appearing correctly.

Symptoms:

- Menu cards appear as plain text
- Event cards appear as plain text
- Little or no visible card separation
- Hover effects not visible
- Shadows not visible

Navbar styling works.

Hero styling works.

Theme colors appear to work.

Likely causes:

1. shadcn Card styles not being applied correctly.
2. CSS theme variables may not be mapped properly.
3. bg-card and background colors may be effectively identical.
4. card.tsx generated by shadcn may have been modified incorrectly.
